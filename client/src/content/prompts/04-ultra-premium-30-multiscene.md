# Ultra-Premium Multi-Scene AI Video Master Prompt Collection

**30 original categories | Multi-scene long-form production prompts | Designed for scene-by-scene generation and editing**

## How to use this collection

These are **master prompts for longer videos**, not single-shot prompts. Generate each scene separately when the video model works best with short clips, or use the scene structure directly in a multi-shot workflow when the model supports it. Each prompt is designed for a complete story or presentation of approximately **60 seconds to 5 minutes**, depending on the number of generated clips and editing pace.

Use the same character reference image, environment reference, product reference, voice profile, color palette, wardrobe, and prop design for every scene. Keep important dialogue exactly as written. If the model cannot reliably generate long dialogue, split each spoken line into its own clip and assemble it during editing.

The reference prompt supplied by the user is reflected in this collection through strict character locking, environment continuity, scene-by-scene planning, suspense or curiosity hooks, clear final beats, lip-sync direction, audio instructions, and platform-ready aspect ratios. The prompt structure is also informed by current guidance from Adobe, Google Veo, LTX, Kling Multi-Shot, Luma, and Runway, which emphasize subject, action, setting, cinematography, lighting, style, sound, shot-level planning, and reference-based consistency. ## Global instruction to append to every prompt

Create a polished, coherent, premium video with consistent character identity, wardrobe, props, environment, lighting logic, voice, and visual style across every scene. Keep anatomy, hands, eyes, mouth movement, object scale, shadows, reflections, and physical contact believable. Use a clear beginning, middle, escalation, resolution, and final memorable beat. Generate scenes in chronological order and use the same reference images for recurring subjects. Dialogue must be spoken by the correct character with accurate lip synchronization. Ambient audio, foley, dialogue, and music must support the action without overpowering speech. Keep important titles, labels, captions, logos, and statistics as editable overlays added in post-production unless the model can render them accurately. Use [16:9 horizontal / 9:16 vertical] according to the platform.
