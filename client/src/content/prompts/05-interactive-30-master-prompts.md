# Interactive 30-Category Premium AI Video Master Prompts

**Purpose:** Each master prompt below is an interactive production system. It does not generate the full video immediately. It first suggests ten topics, waits for the user’s selection, asks for scene count or total duration, and only then generates the full production package.

## Premium continuity principle

AI video models generally have limited memory between separate generations. Therefore, never rely on the model to remember a character or location from an earlier scene. Create a **Continuity Bible** first and paste the relevant locked block into every later image prompt and video prompt. Use a character reference image, location reference image, prop reference image, and approved last frame whenever the tool supports them. Generate one scene at a time, review it, and use its approved final frame as the next scene’s starting reference.

## Universal interactive workflow

Every master prompt in this document must follow this exact interaction order:

**Phase 1 — Topic selection:** Do not create the full story or video. Present exactly ten different topic ideas for the selected category. Each idea must have a title and one-line description. Then ask: “Which topic number would you like to produce?” Stop and wait.

**Phase 2 — Production length:** After the user selects a topic, ask exactly: “How many 10-second scenes do you want, or how many total minutes should the video be?” Accept either a scene count or a duration. Convert minutes into a practical scene plan, clearly stating the number of scenes. Stop and wait for confirmation if the request is ambiguous.

**Phase 3 — Creative brief:** After duration is confirmed, create the title, audience, platform, logline, story arc or teaching arc, visual style, color palette, audio direction, scene list, and production risks.

**Phase 4 — Continuity Bible:** Before scene prompts, create locked entries for every recurring character, object, costume, location, lighting setup, camera language, voice, accent, language, music theme, sound palette, and timeline state. Assign stable IDs such as CHARACTER_A, LOCATION_01, PROP_01, and COSTUME_A.

**Phase 5 — Reference assets:** Create separate ultra-detailed image prompts for the character sheet, location sheet, prop sheet, key pose sheet, and opening frame. These are reference images, not scene images.

**Phase 6 — Scene production:** For every scene, output: scene purpose, duration, continuity state, image prompt, video prompt, camera, action, performance, dialogue or narration, SFX, ambience, transition, end-frame instruction, and a continuity checklist. Use one primary action per generated clip, even when the finished video contains many scenes.

**Phase 7 — Handoff:** After each scene, state which final frame should be used as the next scene’s reference. Never jump to future scenes before the current scene is approved when the user asks for step-by-step mode.

## Universal continuity block

Append this exact block to every image prompt and video prompt, customizing only the bracketed fields:

> **CONTINUITY LOCK:** Use reference assets [CHARACTER IDs], [LOCATION IDs], and [PROP IDs]. Preserve exact identity, face or species features, body proportions, age, hairstyle, clothing, accessories, colors, materials, markings, voice, accent, and personality. Preserve the same environment geometry, furniture, architecture, weather, time of day, lighting direction, shadow softness, color grade, lens feeling, and camera height unless the scene explicitly changes one item. Use the approved final frame of the previous scene as the visual starting reference. Change only the action and shot instructions written for this scene. Maintain physically coherent motion, accurate hands, eyes, mouth movement, object scale, contact shadows, reflections, and temporal continuity.

## Universal scene output format

For each scene use this format:

**Scene [number] — [title]**  
**Duration:** [10 seconds or approved duration]  
**Purpose:** [story, lesson, demonstration, emotional beat, or transition]  
**Continuity state:** [what must remain identical and what is allowed to change]

**Image prompt:** [A complete still-frame prompt for the scene’s approved start or key frame.]

**Video prompt:** [A complete motion prompt beginning with shot type and camera movement, then subject, action, setting, lighting, style, audio, and exact dialogue if required.]

**Camera:** [framing, angle, movement, lens feeling, stabilization]

**Action:** [one primary action and natural reaction]

**Dialogue or narration:** [exact words, speaker, language, pace, lip-sync]

**SFX and ambience:** [specific environmental and foley audio]

**Transition:** [cut, match cut, dissolve, sound bridge, or approved final-frame handoff]

**End-frame reference:** [exact final pose and frame to use as the next scene’s input]

**Quality check:** [identity, geometry, hands, lip-sync, audio, and continuity checks]

# Continuity-first production protocol to append after the selected topic

After the user confirms the topic and duration, perform these steps in order:

1. **Create the Continuity Bible before any scene prompt.** Assign permanent IDs and describe every recurring character, object, wardrobe item, location, time, weather condition, light direction, camera style, voice, accent, and audio motif.

2. **Create reference images first.** Generate a front, three-quarter, side, and full-body character sheet; a location sheet; a prop sheet; and an opening keyframe. Keep the same seed, reference images, model, aspect ratio, and style settings whenever available.

3. **Create a scene-state table.** For each scene record the previous scene’s final pose, character position, gaze direction, hand position, prop state, wardrobe state, lighting, weather, camera height, and emotional state. Do not allow a later prompt to contradict the table.

4. **Generate each scene from the previous approved final frame.** Use image-to-video where possible. If a scene changes location, generate a new location reference first and describe the travel or transition explicitly.

5. **Use a continuity prefix in every prompt.** Repeat the relevant locked IDs and the full visual identity block, because the video model has no dependable memory of earlier prompts.

6. **Use one main action per clip.** A long video may contain many actions, but each 10-second generation should focus on one main action plus a natural reaction. Use multi-shot mode only when the tool supports explicit shot durations, framing, dialogue, and camera movement.

7. **Review before proceeding.** Check face or species identity, clothing, hair, markings, body proportions, hands, props, background geometry, shadows, lighting, camera direction, dialogue, lip-sync, SFX, and end-frame readiness.

8. **Create a correction prompt instead of rewriting everything.** Change only the failed variable—identity, wardrobe, prop, camera, lighting, motion, dialogue, or background—and preserve all other approved details.

9. **Assemble in editing.** Use the approved final frame as the next scene’s starting reference, normalize color and audio, add captions and titles in post-production, and keep a versioned scene ledger.

10. **Final audit.** Confirm that the story or lesson has a clear opening, progression, turning point, resolution, and final frame; that all scenes use the same character and location logic; and that no prompt accidentally introduces an unapproved redesign.
